# 🛒 Electronics eCommerce Shop with Admin Dashboard

This is a **full-stack eCommerce application** built with **Next.js, Node.js, and MySQL**.  
It features both a **customer-facing store** and a **powerful Admin Dashboard** for managing products, orders, and users.

---

## ✨ Features

- 🖥️ Modern and responsive UI using Next.js
- 🔑 Secure authentication & authorization
- 📦 Product browsing, cart, and checkout flow
- 📊 Admin Dashboard with product, user, and order management
- 🗄️ MySQL database integration
- 🚀 Production-ready architecture

---

## ⚙️ Tech Stack

- **Frontend**: Next.js, React, TailwindCSS
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **State Management**: React Query / Context API
